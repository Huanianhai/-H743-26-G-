# 26周期电赛G题解决思路
本设计以 STM32H743 为核心，研制了一套面向 10～500 kHz 周期信号的测量分析 装置。输入信号经 50 Ω BNC 接口、1.65 V 偏置与保护电路后送入 PA5，TIM3 以 2.048  MSPS 触发 ADC1，DMA 完成 4096 点采样。程序采用去直流、Hann 窗、FFT 峰值搜 索、频率插值和多分量联合拟合，计算基频、各频谱分量峰值、总峰峰值和真有效值； 检测到 1 MHz 以上单频干扰时，通过双采样率混叠迁移判据识别干扰并重建被测信号。 测量结果经 USART3 发送至陶晶驰 X2 串口屏，稳定显示 1 个或 3 个完整周期、频谱与 参数。18 组实测中，分量峰值最大绝对误差为 1.7 mV，有效值最大绝对误差为 2.8 mV
